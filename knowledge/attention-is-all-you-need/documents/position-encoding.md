# 위치 인코딩 — 순서를 더하기

“고양이가 개를 쫓았다”와 “개가 고양이를 쫓았다”는 비슷한 단어를 쓰지만 의미가 다릅니다. 어텐션이 토큰의 내용만 본다면 순서 정보를 어디서 얻는지 설명할 수 있어야 합니다.

## 위치별 숫자 무늬를 만듭니다

원문의 sinusoidal positional encoding은 위치마다 사인·코사인 값으로 된 벡터를 만들고 입력 임베딩에 더합니다. 여러 차원에 서로 다른 주기를 사용합니다. 다음은 수식을 읽는 표기입니다.

```text
PE(pos, 2i)   = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))
```

`pos`는 토큰 위치, `i`는 차원 쌍의 번호, `d`는 표현 폭입니다. 짝수 차원과 홀수 차원에 대응하는 파형을 사용합니다. 수식의 목적은 외울 숫자를 늘리는 것이 아니라 위치에 따라 구분되는 신호를 제공하는 것입니다.

## 왜 더하나요?

두 벡터의 폭이 같으므로 더한 뒤에도 `[n, d]` 모양을 유지할 수 있습니다. 다음 층은 토큰 내용과 위치 신호가 결합된 입력을 받습니다. 단순히 토큰을 위치 번호로 바꾸어 버리는 것은 아닙니다.

## 이후 모델과 구분합니다

위치 정보를 쓰는 방법은 여러 가지입니다. 학습 가능한 위치 임베딩도 있고, 어텐션 계산에 회전을 반영하는 RoPE도 있습니다. 사인·코사인을 입력에 더하는 것이 Transformer 전체의 유일한 방식은 아닙니다.
