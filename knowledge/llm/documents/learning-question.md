# 추론 — 학습한 값으로 실행

추론은 학습된 모델을 새 입력에 적용하는 과정입니다. 텍스트 생성에서는 현재 문맥으로 다음 토큰을 예측하고 선택하는 계산을 반복합니다. 일반적인 대화 추론 동안 모델의 가중치는 고정되어 있습니다.

## 대화 속에서 새 내용을 기억하는 이유

사용자가 “내 고양이 이름은 두부입니다”라고 말한 뒤 이름을 물으면, 모델은 그 문장이 입력 문맥에 포함되어 있을 때 답변에 활용할 수 있습니다. 이때 모델의 가중치에 새 정보가 영구적으로 저장되었다고 볼 수는 없습니다.

| 구분 | 바뀌는 것 |
| --- | --- |
| 대화 문맥 | 이번 계산에 들어가는 토큰 목록입니다. |
| 모델 학습 | 신경망 안의 가중치입니다. |
| 앱의 메모리·검색 | 모델 바깥에 저장하거나 다시 찾아오는 정보입니다. |

서비스가 대화를 별도로 저장하거나 나중의 학습에 사용하는지는 해당 서비스의 정책과 구현에 달려 있습니다. 그것은 이번 응답을 계산하는 순간의 추론과 구별해야 합니다.

## 문맥에는 범위가 있습니다

한 번에 처리할 수 있는 문맥의 길이는 모델과 실행 설정에 제한을 받습니다. 긴 대화에서는 일부 내용을 생략하거나 요약해서 전달할 수 있습니다. 따라서 이전에 말한 모든 정보가 매번 입력에 포함된다고 가정하면 안 됩니다.

## 이해를 확인합니다

새 대화에서 고양이 이름을 모른다고 해서 모델의 가중치가 지워진 것은 아닌 이유를 설명해 보십시오.
