# 토큰화 — 문장을 ID로

신경망은 문자열을 그대로 행렬 계산에 사용할 수 없습니다. 토크나이저는 텍스트를 모델의 어휘에 맞게 나누고, 각 조각에 대응하는 정수 ID를 반환합니다. 이 조각을 **토큰**이라고 합니다.

## 단어 수와 토큰 수는 다릅니다

토큰은 단어 전체, 단어의 일부, 문장 부호 또는 바이트 조각일 수 있습니다. 띄어쓰기만으로 문장을 나누는 방식은 아닙니다. 같은 문장도 토크나이저의 어휘와 규칙에 따라 다른 수의 토큰이 될 수 있습니다.

다음은 이해를 위한 가상의 예시입니다. 실제 모델의 분할 결과나 ID가 아닙니다.

```text
문장:    고양이가 잔다
조각:    [고양이] [가] [ 잔다]
토큰 ID: [412]   [27] [8031]
```

## ID에는 크기 순서의 의미가 없습니다

ID 8031이 ID 412보다 의미가 크거나 복잡하다는 뜻은 아닙니다. ID는 어휘 표에서 항목을 구별하는 번호입니다. 이 번호를 실제 계산용 벡터로 바꾸는 것이 다음 단계인 임베딩입니다.

## 왜 중요한가요?

입력 길이 제한은 보통 글자 수가 아니라 토큰 수를 기준으로 합니다. 언어와 표현에 따라 같은 길이의 글도 토큰 수가 달라집니다. 모델에는 학습할 때 사용한 토크나이저와 호환되는 입력을 전달해야 합니다.

## 이해를 확인합니다

문장을 ID 목록으로 바꿨다고 해서 문맥의 의미까지 계산한 것은 아닌 이유를 설명해 보십시오.
