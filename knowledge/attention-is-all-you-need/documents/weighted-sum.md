# Value 가중합 — 정보를 섞기

가중치를 계산했다면 그 비중으로 실제 정보인 Value를 섞습니다. 두 위치가 있다면 출력은 `a₁v₁ + a₂v₂`입니다. 점수를 만들던 Key를 더하는 것이 아니라 Value를 더한다는 점에 주의합니다.

## 공통 예제를 마칩니다

가중치가 약 `[0.670, 0.330]`이고 Value가 `[2, 0]`, `[0, 4]`라고 가정했습니다.

```text
출력 ≈ 0.66976 × [2, 0] + 0.33024 × [0, 4]
     ≈ [1.33952, 1.32095]
```

위치 1을 그대로 복사한 것도, 위치 2의 토큰을 새로 출력한 것도 아닙니다. 여러 위치의 정보가 새로운 벡터에 반영되었습니다.

## 행렬로 묶습니다

가중치 행렬 A가 `[n, m]`이고 V가 `[m, d_v]`이면 `AV`는 `[n, d_v]`가 됩니다. 각 Query에 대해 출력 벡터 하나가 생깁니다. 따라서 어텐션 출력의 위치 수는 Query 수를 따릅니다.

## 아직 다음 토큰 확률이 아닙니다

어텐션 결과는 블록 안의 중간 표현입니다. 여러 층과 FFN 등을 거친 뒤 출력 층에서 어휘 후보 점수로 변환합니다. 어텐션 가중치를 그대로 다음 토큰 확률이라고 부르면 두 종류의 softmax를 혼동하게 됩니다.

위의 직접 계산 예제는 학습된 모델을 해석한 결과가 아니라, 연산을 확인하기 위해 만든 숫자입니다.

## 확인합니다

어텐션 가중치의 열이 가리키는 대상과 마지막 출력 층 확률의 후보가 가리키는 대상은 각각 무엇인지 설명해 보십시오.
