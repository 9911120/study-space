# LLM은 어떻게 작동하나요?

LLM은 대규모 언어 모델입니다. 이 지도에서는 **앞선 문맥을 보고 다음 토큰을 생성하는, 디코더 중심의 언어 모델**을 다룹니다. 모든 언어 모델이 같은 구조나 학습 목표를 사용하는 것은 아닙니다.

## 문장이 답변으로 바뀌는 과정

“대한민국의 수도는”이라는 입력을 생각해 봅니다. 모델이 한 번에 완성된 문장을 꺼내는 대신, 뒤에 이어질 작은 텍스트 조각의 확률을 계산합니다.

1. **토큰화**에서 문장을 조각으로 나누고 각 조각을 ID로 바꿉니다.
2. **임베딩**에서 ID를 숫자 벡터로 바꿉니다.
3. **Transformer**에서 앞선 문맥을 반영해 벡터를 갱신합니다.
4. **생성**에서 다음 토큰을 선택합니다. 새 토큰을 문맥에 붙이고 다음 예측으로 넘어갑니다.

“서울”이 선택되면 문맥은 “대한민국의 수도는 서울”로 늘어납니다. 다음에는 “입니다”에 해당하는 조각을 선택할 수 있습니다. 실제 토큰 경계와 선택 결과는 모델에 따라 달라집니다.

## 채팅도 결국 모델에 들어가는 입력입니다

채팅 앱은 사용자 질문, 이전 대화, 시스템 지시 등을 모델이 기대하는 형식으로 구성합니다. 그중 실제 입력에 포함된 내용이 이번 생성의 문맥이 됩니다. 화면에 과거 대화가 보인다고 해서 그 전체가 항상 모델에 전달되는 것은 아닙니다.

## 예측할 수 있다는 것과 항상 맞는다는 것은 다릅니다

다음 토큰의 확률은 해당 문장이 사실일 확률과 같지 않습니다. 자연스러운 답변도 사실 확인이 필요할 수 있으며, 검색·도구 사용은 모델 바깥의 별도 기능으로 결합할 수 있습니다.

## 이해를 확인합니다

새 토큰을 하나 선택한 뒤 다음 예측의 입력에 무엇이 추가되는지 설명해 보십시오. 문장을 생성하는 과정과 가중치를 학습하는 과정도 구분해 보십시오.
