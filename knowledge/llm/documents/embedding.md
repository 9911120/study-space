# 임베딩 — ID를 벡터로

임베딩은 토큰 ID를 **여러 숫자로 이루어진 벡터**로 바꾸는 과정입니다. 가장 기본적인 형태에서는 어휘의 각 토큰에 벡터 하나를 배정한 표를 사용합니다. 토큰 ID가 들어오면 해당 행을 꺼냅니다.

## 번호에서 계산 가능한 표현으로

다음 숫자는 원리를 설명하기 위한 가상 값입니다.

```text
토큰 ID 412 → 임베딩 표의 412번 행 → [0.2, -0.8, 0.5, ...]
```

이 표의 숫자도 모델의 매개변수이며 학습 과정에서 조정됩니다. 각 차원에 사람이 미리 “동물”, “긍정”, “장소” 같은 의미를 하나씩 지정하는 방식은 아닙니다. 여러 숫자의 조합이 이후 계산에 유용한 특징을 나타냅니다.

## 같은 토큰도 문맥에 따라 달라집니다

일반적인 토큰 임베딩 조회에서는 같은 ID에 같은 시작 벡터를 사용합니다. 하지만 “먹는 배”와 “타는 배”처럼 주변 문맥이 달라지면 Transformer를 통과한 뒤의 표현은 달라질 수 있습니다. 임베딩 표에서 꺼낸 시작 표현과 문맥을 반영한 표현을 구별해야 합니다.

## 토큰의 위치는 어떻게 알까요?

토큰 목록의 순서도 의미에 영향을 줍니다. 모델은 별도의 위치 정보를 사용합니다. 어떤 구조는 위치 벡터를 입력에 더하고, 다른 구조는 어텐션 계산 안에 위치를 반영합니다. 모든 모델이 위치 정보를 임베딩 벡터에 직접 더하는 것은 아닙니다.

## 이해를 확인합니다

토큰 ID, 시작 임베딩, 문맥을 반영한 벡터가 각각 무엇인지 구분해 보십시오.
