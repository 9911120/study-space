# 학습과 추론은 어떻게 다를까요?

## 지금의 질문

대화에서 새 사실을 알려주면 모델의 가중치도 바로 바뀌는 것인지 궁금합니다.

## 구분할 개념

- **학습**은 손실을 바탕으로 가중치를 갱신하는 과정입니다.
- **일반적인 추론**은 주어진 가중치와 입력 문맥으로 출력을 계산하는 과정입니다.
- 대화 내용을 문맥으로 참조하는 것과 가중치를 갱신하는 것은 다릅니다.

서비스가 별도로 제공하는 메모리나 데이터 활용 정책은 모델의 추론 과정과 구분해서 확인해야 합니다.

## 스스로 설명합니다

‘대화에 정보를 더 넣었을 때 답이 달라지는 이유’를 가중치와 문맥이라는 단어를 사용해 설명해 봅니다.
