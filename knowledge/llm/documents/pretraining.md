# 사전 학습

다음 토큰 예측 모델의 사전 학습에서는 텍스트의 앞부분을 보고 뒤에 올 토큰을 예측합니다. 예측과 실제 토큰의 차이를 손실로 계산하고, 이를 줄이도록 매개변수를 갱신합니다.

## 한 번의 학습 단계

1. 학습 데이터에서 토큰 시퀀스를 가져옵니다.
2. 모델이 각 위치에서 다음 토큰의 확률을 계산합니다.
3. 실제 다음 토큰과 비교해 손실을 구합니다.
4. 역전파와 최적화로 가중치를 조정합니다.

이후 지시 따르기 같은 목적에 맞춰 추가 학습을 진행할 수 있습니다. 사전 학습과 후속 학습의 목표는 구분해서 살펴봅니다.
