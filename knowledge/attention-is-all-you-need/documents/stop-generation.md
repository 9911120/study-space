# 종료 — 토큰을 텍스트로 전달

모델이 출력한 ID 목록을 사용자에게 보여주려면 토크나이저의 디코딩 규칙으로 텍스트를 만들어야 합니다. 내부 토큰 하나와 화면의 글자 하나가 항상 일치하는 것은 아닙니다.

## 무엇이 반복을 멈추나요?

대표적으로 종료 토큰(EOS), 최대 생성 토큰 수, 구현된 중지 조건 등이 있습니다. 호출 취소나 실행 오류 역시 결과 전달을 멈출 수 있지만, 모델이 정상적으로 문장을 마친 것과는 다릅니다.

설명을 위한 예로 모델이 300토큰 답변을 이어 쓰려는 상황에서 생성 한도를 100으로 두면 문장이 중간에 끝날 수 있습니다. 이 수치는 실제 모델의 계획 길이를 측정한 것이 아니라 제한의 영향을 설명하는 가정입니다.

## Applied AI 관점의 확인 사항

응답 문자열뿐 아니라 종료 사유와 실제 생성 길이도 살펴보는 습관이 도움이 됩니다. JSON이 잘렸다면 모델의 형식 준수 문제인지, 출력 한도로 끊긴 것인지 먼저 구별할 수 있습니다. 필드 이름과 동작은 사용하는 API나 엔진의 문서를 확인해야 합니다.

## 토큰 선택 정책도 별도입니다

Temperature나 sampling 설정은 어떤 토큰을 선택할지에 영향을 줍니다. 종료 한도는 언제 반복을 멈출지에 영향을 줍니다. 둘을 모두 ‘답변 길이 조절’로 뭉뚱그리면 문제를 잘못 진단할 수 있습니다.
