# Query · Key · Value

Query, Key, Value는 별도의 문서나 데이터베이스가 아닙니다. **현재 층의 토큰 표현에 학습된 선형 변환을 적용해 만든 벡터**입니다. 같은 표현에서도 서로 다른 변환을 적용하므로 역할이 나뉩니다.

## 역할을 나누어 봅니다

- **Query**는 현재 위치가 무엇을 참고할지 비교하는 데 사용합니다.
- **Key**는 각 위치가 얼마나 관련 있는지 Query와 비교되는 벡터입니다.
- **Value**는 가중치를 적용해서 실제로 섞을 정보입니다.

검색어·이름표·내용이라는 비유가 도움이 될 수 있지만, 실제로는 문자열 검색이 아니라 벡터 연산입니다.

## 가중치가 만들어지는 과정

현재 Query와 각 Key의 내적으로 점수를 구하고, Key 차원 수의 제곱근으로 나누어 규모를 조정합니다. 인과적 마스크를 적용한 뒤 softmax로 가중치를 만듭니다. 그 가중치로 Value를 합칩니다.

```text
출력 = softmax(QKᵀ / √dₖ + 마스크) V
```

참고 가능한 두 위치의 가중치가 0.8과 0.2라면 출력은 `0.8 × V₁ + 0.2 × V₂`입니다. 이는 이해를 위한 가상 수치입니다. 한 위치의 토큰을 그대로 복사하는 것이 아니라, 여러 위치의 정보 벡터를 섞습니다.

## 이해를 확인합니다

가중치를 구하는 데 쓰는 벡터와 가중치를 곱해서 합치는 벡터를 구분해 보십시오.
