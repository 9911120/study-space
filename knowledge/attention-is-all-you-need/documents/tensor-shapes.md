# 벡터·행렬·텐서의 모양

모델 코드의 `shape`는 숫자 배열의 각 축 길이를 나타냅니다. 수식을 구현으로 연결할 때 가장 먼저 확인할 정보입니다. 벡터는 한 축, 행렬은 두 축, 텐서는 이를 더 일반화한 표현입니다.

## 작은 예제의 모양을 따라갑니다

토큰 3개를 폭 4의 벡터로 표현하고, 한 헤드의 Q·K·V 폭을 2로 만드는 상황을 가정합니다.

| 값 | 모양 | 의미 |
| --- | --- | --- |
| X | `[3, 4]` | 토큰 3개의 입력 표현입니다. |
| W_Q | `[4, 2]` | 입력 특징을 Query 특징으로 바꿉니다. |
| Q, K, V | `[3, 2]` | 위치별 역할 벡터입니다. |
| QKᵀ | `[3, 3]` | 모든 Query–Key 쌍의 점수입니다. |
| softmax(QKᵀ / √2)V | `[3, 2]` | Query마다 모은 정보입니다. |

행렬 곱에서 가운데 차원이 맞아야 합니다. `[3, 2] × [2, 3]`은 `[3, 3]`이 됩니다. 단순히 같은 위치끼리 곱하는 원소별 곱과 다릅니다.

## 배치와 헤드를 더합니다

여러 문장과 여러 헤드를 함께 처리할 때 `[B, H, N, D]` 같은 모양을 볼 수 있습니다. B는 배치, H는 헤드, N은 토큰, D는 헤드 폭입니다. 실제 코드의 축 순서는 구현에 따라 달라집니다.
