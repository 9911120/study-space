# 생성 — 예측하고 이어 쓰기

Transformer가 만든 마지막 위치의 표현을 출력 층에 통과시키면, 어휘의 각 토큰에 대한 점수를 얻습니다. 이 점수를 **로짓(logit)**이라고 합니다. Softmax는 점수를 합이 1인 확률 분포로 변환합니다.

## 확률 분포에서 토큰 하나를 고릅니다

“대한민국의 수도는” 뒤에 올 후보를 다음처럼 가정해 봅니다. 수치는 설명을 위한 가상 예시이며 실제 모델 결과가 아닙니다.

| 다음 토큰 후보 | 예시 확률 |
| --- | --- |
| 서울 | 0.72 |
| 부산 | 0.04 |
| 그 밖의 후보 전체 | 0.24 |

매번 가장 높은 확률을 선택하는 방법도 있고, 확률에 따라 후보를 추출하는 방법도 있습니다. Temperature는 분포의 뾰족함에 영향을 주고, top-p 같은 방법은 추출할 후보 범위를 제한합니다. 이는 진실성을 보장하는 설정이 아닙니다.

## 답변 전체가 한 번에 결정되지는 않습니다

선택한 토큰을 기존 문맥에 붙이고 다음 토큰의 분포를 계산합니다. 종료 토큰, 최대 생성 길이 또는 별도의 중지 조건에 도달할 때까지 이어갑니다. 생성된 ID들을 디코딩하면 화면에 보이는 텍스트가 됩니다.

이 설명은 일반적인 순차 생성의 개념적 흐름입니다. 실제 구현은 KV 캐시 등을 사용해 앞부분의 계산 결과를 재사용할 수 있습니다. 따라서 매번 전체 문장을 처음부터 똑같이 재계산한다고 이해하면 부정확합니다.
