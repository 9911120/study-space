# 후속 학습

사전 학습으로 글의 패턴을 배웠다고 해서 사용자의 지시를 항상 원하는 방식으로 따르는 것은 아닙니다. 후속 학습은 기반 모델의 응답 행동과 품질을 목적에 맞게 다듬는 단계입니다.

## 지도 미세 조정으로 답변 예시를 학습합니다

“다음 내용을 세 문장으로 요약하십시오”라는 요청과 그에 맞는 답변을 예시로 학습시킬 수 있습니다. 이를 통해 모델이 지시, 대화 형식, 응답 스타일 등에 적응하도록 만듭니다. 이 과정에서도 가중치가 갱신됩니다.

## 선호 신호를 이용할 수도 있습니다

같은 질문에 대한 여러 응답 중 어떤 응답이 더 좋은지 평가한 데이터를 사용할 수 있습니다. 인간 피드백 기반 강화학습과 직접 선호 최적화 등 여러 방법이 있으며, 모든 모델이 같은 방법을 쓰는 것은 아닙니다.

핵심은 다음 토큰 예측을 없애는 것이 아니라, 생성되는 응답이 원하는 행동에 더 가까워지도록 모델을 조정한다는 점입니다.

## 프롬프트와는 무엇이 다른가요?

프롬프트는 이번 추론에 주어지는 입력입니다. 후속 학습은 예시와 학습 절차로 가중치를 변경합니다. 프롬프트에 “친절하게 답하십시오”라고 넣는 것과, 친절한 응답 데이터를 사용해 모델을 학습하는 것은 다른 일입니다.

## 이해를 확인합니다

입력을 바꾸는 것과 가중치를 바꾸는 것의 차이를 프롬프트와 후속 학습에 연결해 설명해 보십시오.
