# Multi-Head — 여러 결과 결합

지금까지는 한 헤드의 어텐션을 계산했습니다. Multi-Head Attention은 다른 Q·K·V 변환을 사용하는 여러 헤드에서 비슷한 계산을 수행하고 결과를 결합합니다.

## 여러 개의 완전한 대형 모델이 아닙니다

모델 폭이 8이고 헤드가 2개인 작은 예시를 생각합니다. 각 헤드의 벡터 폭을 4로 잡으면 헤드별 출력은 `[n, 4]`입니다. 이를 특징 축으로 이어 붙여 `[n, 8]`을 만들고 출력 행렬 W_O를 곱합니다. 이 수치는 구조를 설명하기 위한 예시입니다.

```text
헤드 1의 출력 ─┐
               ├─ 특징 축으로 연결 → 출력 투영 W_O
헤드 2의 출력 ─┘
```

캔버스에서 이 카드가 마지막에 있는 이유는 앞서 설명한 **헤드별 출력들을 결합하는 단계**이기 때문입니다. 헤드 1을 끝내야 헤드 2를 계산할 수 있다는 뜻은 아닙니다.

## 왜 여러 헤드를 사용하나요?

하나의 점수표와 가중합으로 정보를 모으는 것보다 여러 변환 공간에서 관계를 계산할 수 있습니다. 그렇다고 ‘주어 담당 헤드’, ‘감정 담당 헤드’처럼 고정된 담당을 사람이 지정하는 것은 아닙니다.

## 학습 파라미터와 실행 비용

헤드 수를 바꿀 때 모델 폭을 고정하는지, 헤드 폭을 고정하는지에 따라 계산량과 파라미터 변화가 다릅니다. 헤드 수만 보고 비용이 몇 배라고 단정하지 않습니다.
