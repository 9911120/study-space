# 역전파와 가중치 갱신

**기울기**는 어떤 값을 조금 바꿀 때 손실이 어느 방향으로 얼마나 달라지는지 나타내는 정보입니다. 신경망은 많은 행렬 연산을 연결하므로, 그 연결을 따라 미분 정보를 전달하는 역전파를 사용합니다.

## 계산과 갱신은 별개입니다

```text
forward:  입력 → 예측 → 손실
backward: 손실 → 각 가중치의 기울기
update:   optimizer가 기울기로 가중치를 변경합니다.
```

역전파가 답변 문장을 거꾸로 생성한다는 뜻은 아닙니다. 예측을 만든 계산 그래프를 따라 기울기를 구하는 과정입니다. Adam 같은 optimizer는 기울기의 누적 통계 등을 이용해 갱신합니다.

## 이번 입력의 값과 모델의 값을 나눕니다

Q, K, V와 중간 토큰 표현은 입력을 처리하며 생기는 활성값입니다. 임베딩 표나 W_Q 같은 행렬은 여러 요청에서 사용하는 모델 파라미터입니다. 일반적인 추론은 활성값을 계산하지만, 손실에 대한 역전파와 optimizer 갱신을 하지 않습니다.

## 프롬프트를 잘 쓰면 모델이 학습되나요?

프롬프트를 바꾸면 입력 문맥이 달라져 출력이 달라질 수 있습니다. 그것만으로 모델 가중치가 영구적으로 바뀌었다고 할 수는 없습니다. 앱의 메모리 저장, 문맥 내 예시 활용, 별도의 미세 조정은 서로 다른 층위의 동작입니다.

## 확인합니다

모델을 다시 호출할 때 Q가 달라지는 경우와 W_Q가 달라지는 경우를 각각 예로 들어 보십시오.
