# RNN·LSTM — 순서대로 읽기

RNN은 순서가 있는 입력을 다루는 신경망입니다. 각 단계에서 현재 입력과 직전의 **은닉 상태**를 받아 새 상태를 만듭니다. 은닉 상태는 사람이 읽는 메모가 아니라, 지금까지의 입력을 반영한 숫자 벡터입니다.

```text
새 상태 hₜ = f(현재 입력 xₜ, 이전 상태 hₜ₋₁)
```

## 프로그램으로 생각합니다

문장을 토큰 배열로 놓고, `state = update(state, token)`을 반복하는 루프를 생각하면 됩니다. 세 번째 상태를 계산하려면 두 번째 상태가 있어야 합니다. 여러 문장을 동시에 처리하는 배치 병렬화는 가능하지만, 한 문장 안의 모든 상태를 독립적으로 한꺼번에 만들기는 어렵습니다.

## LSTM이 해결하려던 문제

멀리 떨어진 입력의 영향이 반복 연산과 학습을 거치며 약해지는 문제를 다루기 위해 LSTM이 제안되었습니다. 1997년 논문으로 알려진 LSTM은 정보를 유지하거나 갱신하는 게이트와 셀 상태를 사용합니다. 이를 단순히 “RNN은 기억을 전혀 못한다”라고 해석하면 안 됩니다.

중요한 구분은 **정보를 잘 보존하는가**와 **시간축의 계산 의존성이 있는가**입니다. LSTM이 전자를 개선해도, 새 상태가 직전 상태에 의존한다는 구조는 남습니다.

## 다음 연구로 이어지는 질문

문장 한 개의 분류를 넘어, 길이가 다른 다른 언어의 문장을 출력하려면 어떻게 해야 할까요? 입력을 읽는 모델과 출력을 쓰는 모델을 연결하는 인코더·디코더 발상이 등장합니다.
