# LLM은 어떻게 작동할까요?

LLM은 대규모 언어 모델(Large Language Model)을 뜻합니다. 이 지도에서는 **다음 토큰을 예측하는 생성형 언어 모델**을 중심으로 공부합니다.

## 큰 그림

1. **토큰화**: 입력 텍스트를 토큰 ID로 바꿉니다.
2. **임베딩**: 각 ID를 벡터로 바꿉니다.
3. **Transformer**: 토큰 사이의 관계를 반영해 표현을 갱신합니다.
4. **예측**: 다음 토큰 후보의 확률을 계산합니다.
5. **생성**: 토큰을 선택하고, 이어서 다음 토큰을 예측합니다.

> 첫 번째 목표는 모든 수식을 외우는 것이 아니라, 입력부터 출력까지의 흐름을 자신의 말로 설명하는 것입니다.

## 이어서 생각합니다

‘텍스트가 숫자로 바뀐다’는 말이 막연하다면 **토큰화**부터 시작합니다. 숫자로 표현된 텍스트가 어떻게 문맥을 반영하는지 궁금하다면 **Transformer**로 이동합니다.
