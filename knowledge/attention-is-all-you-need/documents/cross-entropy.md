# 손실 — 정답에 준 확률 평가

손실 함수는 현재 모델의 예측이 학습 목표에서 얼마나 벗어났는지 숫자로 나타냅니다. 다음 토큰 예측에서 정답이 하나인 기본 경우, 교차 엔트로피 손실은 정답 토큰 확률의 음의 로그로 이해할 수 있습니다.

```text
손실 = -log(정답 토큰에 준 확률)
```

## 두 예측을 비교합니다

정답이 ‘차’라는 토큰이라고 가정합니다. 정답에 0.8의 확률을 준 모델은 손실이 약 0.223이고, 0.2를 준 모델은 약 1.609입니다. 자연로그를 쓴 예시입니다. 정답에 더 높은 확률을 준 예측의 손실이 작습니다.

학습에서는 여러 위치와 여러 예시의 손실을 모읍니다. 패딩 위치가 잘못 학습 표적에 포함되지 않도록 처리하는 것도 중요합니다.

## 구현에서 혼동하기 쉬운 점

PyTorch의 `CrossEntropyLoss`는 일반적인 클래스 표적 사용에서 정규화 전 로짓을 입력으로 받으며, 내부에서 log-softmax에 해당하는 계산을 포함합니다. 앞에서 softmax를 한 값을 무조건 다시 넣는 방식으로 작성하면 안 됩니다.

## 왜 생성 결과도 평가하나요?

손실은 데이터의 정답에 대한 예측 목표를 측정합니다. 사용자에게 유용한가, 사실인가, 원하는 형식인가를 전부 같은 숫자로 보장하지는 않습니다. label smoothing을 쓰면 표적 분포 자체도 달라집니다.

## 확인합니다

가장 높은 확률의 토큰을 틀리게 골랐다는 사실 외에, 정답 토큰에 얼마나 확률을 주었는지가 학습에 유용한 이유를 설명해 보십시오.
