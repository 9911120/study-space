# BERT·GPT와 파운데이션 모델

2017년 번역 모델 이후 Transformer 계열은 다양한 방향으로 발전했습니다. 구조 이름과 모델을 학습·활용하는 방식을 같은 개념으로 섞지 않는 것이 중요합니다.

| 계열 | 대표적인 사용 방식 |
| --- | --- |
| 인코더 중심 | 입력의 양방향 문맥 표현을 만들고 분류·추출 등에 활용합니다. BERT가 대표적입니다. |
| 디코더 중심 | 앞선 토큰을 조건으로 다음 토큰을 예측합니다. GPT 계열이 대표적입니다. |
| 인코더·디코더 | 입력을 별도로 표현하고 그 정보를 참고해 출력을 생성합니다. 원문 번역 모델이 해당합니다. |

## BERT와 GPT의 역사적 차이

2018년 GPT 연구는 언어 모델 사전 학습과 과제별 미세 조정을 연결했습니다. 같은 해 BERT는 양방향 Transformer 표현의 사전 학습을 발전시켰습니다. 두 모델이 같은 구조를 그대로 쓰고 출력 UI만 바꾼 것은 아닙니다.

## 파운데이션 모델은 또 다른 축입니다

넓은 데이터로 학습한 모델을 여러 후속 과제로 적응시키는 관점입니다. 모든 파운데이션 모델을 텍스트 생성 모델이라고 부를 수 없고, 모든 Transformer를 대규모 파운데이션 모델이라고 부를 수도 없습니다.

## 채팅 제품까지 가려면

대화형 모델은 사전 학습 외에 지시 따르기와 선호 기반 후속 학습 등을 사용할 수 있습니다. 서비스에는 검색, 도구, 메모리 저장, 안전 정책과 실행 인프라도 결합됩니다. 이 모든 요소가 2017년 논문의 모델 그림에 이미 들어 있었다고 읽지는 않습니다.
