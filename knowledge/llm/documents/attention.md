# Self-Attention

Self-Attention은 같은 입력 시퀀스 안의 토큰 표현들을 서로 연결하는 계산입니다. 각 위치에서 **어떤 위치의 정보를 얼마나 모을지** 가중치를 구하고, 그 가중치로 정보 벡터를 섞습니다.

## ‘참고한다’를 계산으로 바꿉니다

“민수는 책을 집었다. 그는 읽기 시작했다.”라는 문장을 생각해 봅니다. ‘그’의 표현을 만들 때 앞서 나온 사람에 관한 정보가 도움이 될 수 있습니다. 어텐션은 이런 문맥 의존성을 학습할 수 있는 계산 구조를 제공합니다.

다만 모델 내부에서 특정 헤드가 항상 ‘대명사의 대상을 찾는 담당자’처럼 작동한다고 단정할 수는 없습니다. 이 문장은 원리를 이해하기 위한 예시입니다.

## 세 가지 벡터를 사용합니다

입력 표현에서 Query, Key, Value를 만듭니다. Query와 각 Key의 비교 결과를 가중치로 바꾸고, 그 가중치로 Value들을 합칩니다. 구체적인 숫자 흐름은 아래의 Query · Key · Value 카드에서 살펴봅니다.

## 미래는 가리고, 여러 관점으로 계산합니다

인과적 Self-Attention은 현재 위치보다 뒤의 위치를 가립니다. Multi-head attention은 여러 어텐션 계산을 나누어 수행하고 결과를 결합합니다. 헤드마다 다른 관계를 표현할 수 있지만, 그 역할을 사람이 하나씩 지정하지는 않습니다.

## 이해를 확인합니다

어텐션의 출력이 토큰 하나를 고르는 결과인지, 여러 정보 벡터를 섞은 결과인지 구분해 보십시오.
