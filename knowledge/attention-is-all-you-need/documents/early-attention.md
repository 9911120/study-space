# 2014–2015 · 다시 참고하기

Bahdanau 등의 연구는 2014년 프리프린트로 공개되고 ICLR 2015에서 발표되었습니다. 핵심 발상은 디코더가 출력할 때마다 원문의 여러 위치에서 필요한 정보를 다르게 모으도록 하는 것입니다.

## 번역할 때 참고할 위치가 달라집니다

“I love this book”을 번역할 때 ‘책’에 해당하는 출력을 만드는 순간과 ‘좋아한다’에 해당하는 출력을 만드는 순간에는 참고할 입력 정보가 다를 수 있습니다. 이 예시는 역할을 설명하기 위한 것이며 실제 학습된 정렬 결과는 아닙니다.

입력의 각 위치에 표현을 남겨두고, 현재 디코더 상태와의 관련도를 계산합니다. 관련도를 정규화한 가중치로 입력 표현들을 더해 **문맥 벡터**를 만듭니다.

## 딱 한 단어를 집는 방식만 있는 것은 아닙니다

일반적인 soft attention은 여러 위치에 연속적인 가중치를 줍니다. 그래서 “참고할 문서 하나를 검색한다”기보다 “여러 정보 벡터를 학습된 비중으로 섞는다”에 가깝습니다. 이 계산은 다른 모델 부분과 함께 학습할 수 있습니다.

## Transformer와의 차이

이 단계의 어텐션은 주로 순환 신경망에 붙어 있었습니다. Transformer는 이와 같은 아이디어의 흐름 위에서, 순환 계산을 없앤 구조를 제안합니다. 따라서 논문 제목을 “어텐션을 처음 발견했다”로 읽으면 역사적 맥락을 놓치게 됩니다.

## 확인합니다

고정 크기 요약만 전달하는 방식과, 원문의 위치별 표현을 매 출력 단계에서 참고하는 방식의 차이를 설명해 보십시오.
