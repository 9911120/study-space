# 사전 학습

사전 학습은 모델의 가중치가 많은 데이터의 패턴을 익히는 단계입니다. 여기서는 텍스트의 앞부분으로 다음 토큰을 맞히는 **인과적 언어 모델링**을 예로 듭니다.

## 텍스트 자체에서 학습 문제를 만듭니다

토큰 목록이 `[A, B, C, D]`라면 A 뒤의 B, A·B 뒤의 C, A·B·C 뒤의 D를 예측하는 문제가 됩니다. 정답이 원래 텍스트에 있으므로 사람이 문장마다 별도의 정답 문구를 작성할 필요가 없습니다.

## 예측의 오차가 가중치를 바꿉니다

모델은 정답 토큰 하나만 출력하는 대신 어휘 전체에 대한 확률을 계산합니다. 일반적인 교차 엔트로피 손실은 실제 다음 토큰에 높은 확률을 주도록 학습 신호를 만듭니다. 역전파로 기울기를 구하고 최적화 알고리즘이 가중치를 조정합니다.

```text
텍스트 → 다음 토큰 예측 → 손실 계산 → 기울기 계산 → 가중치 갱신
```

## 단순한 목표에서 다양한 패턴을 익힙니다

다음 내용을 잘 예측하려면 문법, 표현 방식, 문맥의 관계 등 여러 패턴이 유용합니다. 모델은 반복 학습으로 이런 패턴을 매개변수에 반영할 수 있습니다. 다만 텍스트에서 배운 패턴이 사실의 정확성이나 일관된 추론을 보장하지는 않습니다.

## 이해를 확인합니다

일반적인 답변 생성 과정과 달리, 여기서는 어떤 계산을 거쳐 가중치 자체가 바뀌는지 설명해 보십시오.
