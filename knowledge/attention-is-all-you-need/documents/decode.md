# 디코드 — 새 토큰으로 이어가기

첫 번째 새 토큰을 선택한 뒤에는 그 토큰까지 포함한 문맥으로 다음 출력을 계산합니다. 일반적인 자기회귀 생성의 핵심은 다음과 같은 의존성입니다.

```text
토큰 A 선택 → A를 포함해 계산 → 토큰 B 선택 → B를 포함해 계산
```

## 캐시가 해주는 일

KV 캐시를 사용하는 일반적인 실행은 새 토큰의 Q·K·V를 계산하고, 과거에 저장한 K·V를 함께 사용합니다. 앞부분의 중간 계산을 매번 똑같이 다시 만들 필요를 줄입니다. 하지만 새 Query가 과거 문맥을 참고하는 계산 자체가 사라지는 것은 아닙니다.

## 학습과 다른 점

학습 때는 정답 앞부분을 모두 알고 있어 입력으로 제공할 수 있습니다. 생성 때는 아직 선택하지 않은 토큰이 무엇인지 모르므로 같은 방식으로 모든 미래 위치의 입력을 만들 수 없습니다.

Speculative decoding 등 여러 토큰 후보를 활용하는 가속 방식도 있지만, 여기서는 기본적인 자기회귀 실행을 이해하는 데 집중합니다. 모든 실제 엔진이 단순한 한 토큰 루프로만 구현된다고 단정하지 않습니다.

## 스트리밍과 병렬화

UI가 토큰이나 텍스트 조각을 나누어 받는 것은 전달 방식입니다. 스트리밍을 켠다고 모델이 답변 전체를 병렬로 계산하도록 구조가 바뀌지는 않습니다. 출력 길이가 길어지면 반복 횟수가 늘어날 수 있습니다.
