# 토큰화

모델은 문자를 그대로 계산하지 않습니다. 토크나이저가 텍스트를 조각으로 나누고 각 조각에 **숫자 ID**를 부여합니다.

## 토큰은 단어와 같지 않습니다

토큰은 단어 전체일 수도 있고, 단어의 일부나 문장 부호일 수도 있습니다. 동일한 문장도 토크나이저에 따라 다르게 나뉩니다.

```text
텍스트 → 토큰 조각 → 토큰 ID → 임베딩 벡터
```

토큰 ID 자체의 크기는 의미의 크기를 나타내지 않습니다. ID는 어휘표에서 항목을 찾아가기 위한 번호입니다.

## 이해 확인

- [x] 토큰 ID와 임베딩 벡터를 구분합니다.
- [ ] 한국어 문장 하나를 실제 토크나이저로 나누어 봅니다.
